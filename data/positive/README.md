# Positive Samples

Put your actual wake phrase recordings here.

Recommended format:

```text
16 kHz / mono / 16-bit PCM WAV
```

Example names:

```text
hey_komi_001.wav
hey_komi_002.wav
hey_komi_003.wav
```

Public keyword datasets are useful for sanity checks, but phrase-specific wake word positives should come from generated samples, your own recordings, or consenting testers.
