# Examples

These files show what a successful local smoke test and generated ESPHome output look like.

- [RTX 5070 Ti smoke test](rtx-5070-ti-smoke-test.md)
- [Hey Komi ESPHome snippet](hey-komi/esphome-snippet.yaml)
- [Empty dataset manifest example](hey-komi/dataset_manifest.empty.example.json)

The smoke test does not prove that a custom wake word is accurate on hardware. It proves the local GPU, Docker runtime, trainer UI, and manifest/export scripts are wired correctly.
